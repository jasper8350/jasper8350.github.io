1. 최소 수집 원칙

BrewMate(이하 "앱")는 기능 제공에 반드시 필요한 항목만 수집합니다. 로그인 없이도 레시피 열람, 타이머, 분쇄도 측정, 기기 내 기록을 모두 사용할 수 있으며 이때 계정 정보는 수집하지 않습니다.

iOS 광고 제거 구매의 결제 정보와 구매 내역은 Apple 이 처리하며, 앱은 기기 안에 구매 만료 시각만 저장하고 서버로 보내지 않습니다. Android 앱에는 유료 상품이 없습니다.

2-1. 레시피 공유 링크

"공유" 단추로 만든 링크에는 레시피 내용(이름 · 드리퍼 · 원두량 · 단계)만 들어 있고 계정 정보나 기록은 들어가지 않습니다. 링크는 서버에 저장되지 않으며, 링크를 아는 사람은 누구나 열 수 있습니다.

3. 카메라 이미지

분쇄도 측정을 위해 촬영한 사진은 기기 안에서만 분석되며 서버로 전송되지 않습니다. 사진은 어디에도 저장하거나 전송하지 않고, 분석 결과 수치만 기록에 남습니다. 사진첩에는 접근하지 않습니다.

4. 이용 목적

계정 식별과 로그인 유지, 기기 간 기록 동기화, 분쇄도 근사 분석, 오류 대응, 광고 기반 무료 서비스 운영에 사용합니다. 프로필링, 맞춤 콘텐츠 추천, 마케팅 발송에는 사용하지 않습니다.

5. 처리 위탁과 국외 이전

  • Supabase — 계정 인증과 사용자 기록 저장
  • Vercel — 웹 서비스와 분쇄도 분석 API 호스팅
  • Google AdMob — 광고 게재와 동의 관리

각 사업자의 데이터 처리 지역과 정책은 해당 사업자의 약관을 따릅니다.

6. 광고와 개인화 거부

광고는 비개인 맞춤 광고를 기본으로 요청하며, 동의 화면(UMP)에서 동의를 받은 뒤에만 요청합니다. 동의 내용은 앱 설정 → 광고 개인정보 옵션에서 언제든 다시 선택할 수 있습니다. 설정에서 보상형 광고를 끝까지 보면 24시간 동안 광고가 표시되지 않습니다.

7. 보관과 삭제

계정과 기록은 사용자가 삭제하거나 계정을 삭제할 때까지 보관합니다. 삭제 방법은 두 가지입니다.

  • 앱: 설정 → 계정 → 계정 삭제 (기기 내 기록은 설정 → 데이터 저장 → 이 기기 기록 삭제)
  • 앱에 들어갈 수 없을 때: 계정 · 데이터 삭제 안내

계정을 삭제하면 계정에 연결된 추출 기록, 분쇄도 기록, 레시피 설정(즐겨찾기 · 기본값 · 내 레시피), 원두 노트, 설정 값이 함께 즉시 삭제됩니다.

8. 이용자 권리

이용자는 자신의 데이터 열람, 서버 저장 중단(앱 설정의 계정 동기화 끄기), 삭제를 언제든 직접 실행할 수 있습니다. 로그인 화면에는 수집 항목 · 목적 · 보유 기간 · 거부권을 안내하며, 동의하지 않아도 로그인 없이 모든 기능을 쓸 수 있습니다.

9. 아동

이 서비스는 만 14세 미만 아동을 대상으로 하지 않으며 아동을 대상으로 개인정보를 수집하지 않습니다.

10. 안전성 확보 조치

모든 전송은 HTTPS 로 암호화합니다. 서버의 사용자 기록은 계정별 접근 제어(RLS)로 본인만 읽고 쓸 수 있으며, 분석 API 는 이미지를 저장하지 않고 응답 후 폐기합니다.

11. 변경 고지

이 방침이 바뀌면 이 페이지의 시행일을 갱신하고, 수집 항목이 늘어나는 변경은 앱 안에서 별도로 알립니다.
